# 坐直评分算法

## 前提

算法假设摄像头、座椅和主要拍摄距离保持稳定。摄像头移动后，画面中的绝对高度会变化，因此必须重新校准。

## 校准

用户自然坐直约 3 秒时，程序采集多帧 MediaPipe Pose Landmarker 关键点并取中位数，建立当前摄像头的个人基线。基线只保存数值特征，不保存画面。

## 特征

当前版本融合六类信号：

| 信号 | 含义 | 权重 |
| --- | --- | ---: |
| 头部高度下降 | 最高可见面部点在画面中下移 | 38% |
| 头部放大 | 双耳、双眼或嘴角跨度增大，提示靠近摄像头 | 22% |
| 肩膀下降 | 双肩中点下移 | 13% |
| 躯干缩短 | 肩膀到髋部的画面高度减少 | 12% |
| 颈肩压缩 | 头部中心到肩膀的垂直距离减少 | 9% |
| 深度前移 | MediaPipe 相对深度显示头部前移 | 6% |

各信号根据相对个人基线的偏移归一化到 0–100，再按权重合成分数。实时分数使用指数平滑，降低关键点抖动。

## 状态与提醒

- 默认分数低于 40：坐直；
- 接近阈值：宠物轻微前倾；
- 达到阈值：宠物塌坐，界面立即显示持续时间；
- 超过快速确认时间：发送系统通知；
- 连续超过长期弹窗时间：宠物弹出醒目提醒。

短暂丢失关键点不会立即判定离座。只有连续未检测到人达到离座确认时间后，程序才进入离座状态并重置久坐周期。

## 局限

- 强逆光、遮挡、宽松衣物和极端摄像头角度会降低准确度；
- 正面画面更适合观察高度，侧前方画面更容易体现头部前伸；
- 算法衡量的是“相对个人校准姿势的变化”，不能判断脊柱疾病；
- 多人同时进入画面时，MediaPipe 选择的目标可能变化。
